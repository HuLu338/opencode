Run one bounded cost-aware coding workflow as a single deterministic operation.

Provide the original request, routing attributes, exact allowed files, and the smallest deterministic validation commands. The tool owns `.opencode/task-state/<task_id>.json`, delegates implementation to the routed coding role, records actual session usage, runs the supplied validation commands, retries or escalates within policy, and obtains an independent Reviewer decision from a different provider/model. Each role uses its bounded configured model pool; classified provider or model failures move to the next candidate without consuming an implementation attempt.

Use `resume: true` only to continue an existing task state after an interrupted tool call. Never run this tool concurrently for the same task ID. When the configured Docker sandbox is enabled, deterministic validation runs with a read-only repository mount, bounded resources, no extra capabilities, and no network by default; unavailable Docker infrastructure is recorded as unavailable validation instead of an implementation failure. Cost and budget status explicitly report when pricing is incomplete instead of treating missing prices as zero; an unevaluable configured budget blocks further model calls. The final output is authoritative: `completed` requires deterministic validation, different concrete author and Reviewer identities, and an explicit Reviewer `PASS`.
